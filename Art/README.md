# Art

All art comes from Dragon Game Dev’s November 12, 2026 DragonTales IPA (`dt11`). Loose PNGs/JPEGs and the two JSON data files were copied as shipped (the shadow→star rename was already applied in that build).

`app_icon_1024.png` is the one addition from the same art set (`dragon-tales-art/v2/ui`), used because `Assets.car` in the IPA could not be unpacked.

Do not generate or replace these assets. Keep filenames stable (`icon_gem.png` is a pink scale, not a gemstone).
